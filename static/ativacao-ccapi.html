Ativação CCAPI da EOS R10 (uma única vez)

  1. Atualize a R10 para firmware 1.8.0 (Canon site → R10 → drivers).
  2. Crie conta gratuita em developercommunity.usa.canon.com → solicite Camera API Package (CAP/CCAPI) → baixe a Activation Tool.
  3. Conecte a R10 via USB só para ativar → rode a Activation Tool → ative CCAPI na câmera.
  4. Na câmera: Menu → Funções wireless → Wi-Fi/Bluetooth → CCAPI → Ativar → conecte no mesmo Wi-Fi do Mac.
  5. Anote o IP da câmera (mostrado no LCD ou no roteador) e digite no app → Conectar.
  6. Depois disso: nunca mais use USB. Só Wi-Fi.

Dicas: bateria cheia ou dummy battery; rede 5GHz perto do roteador; se cair, o app reconecta sozinho (backoff até 10s); se o Zoom não enxergar a câmera, abra o OBS → Start Virtual Camera → Stop → feche o OBS e inicie pelo app.
